# Day15. 실시간 YOLO 객체 탐지 실험

## 1. 프로젝트 개요

사전학습 YOLO 모델을 활용하여
웹캠 환경에서 실시간 객체 탐지를 수행하고,
환경 조건에 따른 객체 탐지 결과를 비교한다.

## 2. 실험 목적

동일한 물체라도 거리, 크기, 가림 여부 및
배경 환경에 따라 모델의 탐지 결과가 달라지는지 관찰한다.

## 3. 실험 환경

- 대상 물체: 텀블러
- Confidence Threshold: 0.25
- 탐지 방식: 실시간 웹캠 객체 탐지
- 비교 조건: 거리, 가림 여부, 배경 환경

## 4. 실험 결과

### 실험 1. 거리 변화

가까운 거리에서는 remote 0.64,
먼 거리에서는 remote 0.58로 탐지되었다.

### 실험 2. 동일 거리에서 클래스 변화

비슷한 거리에서도 remote에서 bottle로
예측 클래스가 변경되는 현상을 관찰했다.

### 실험 3. 물체 가림 여부

텀블러 하단을 가린 경우 cup 0.44,
가리지 않은 경우 bottle 0.72로 탐지되었다.

## 5. 주요 관찰

동일한 텀블러에 대해서도 입력 영상의 조건에 따라
모델의 예측 클래스와 confidence가 달라질 수 있었다.

## 7. 결론

객체 탐지 결과는 물체 자체의 특성뿐 아니라
입력 영상의 촬영 조건과 주변 환경에도 영향을 받을 수 있다.

Confidence 점수는 예측 신뢰 점수이며,
실제 정확도와 동일한 의미가 아니다.
